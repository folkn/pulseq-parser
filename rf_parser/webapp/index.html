Pulseq Single-Channel Sequence Builder

Enter MRI sequence parameters and generate a single-RF-channel Pulseq waveform description — a schema-compliant .json file (per rf_parser/schema.md) and a matching .seq file readable by rf_parser/rf_waveform_parser.py — plus a live pulse-sequence diagram. Timing uses a simplified small-tip-angle RF amplitude model; it is a parameter/waveform generator for downstream tooling, not a full Bloch simulation.
